データ管理

チャット・リマインダーは全部このiPhone内に保存。画像バイナリは保存しません。

IPA・7日署名について

GitHub Actionsで作った署名なしIPAをSideloadly / AltStoreで入れます。無料Apple IDは7日で期限切れ→入れ直し。データはバックアップ書き出しで退避できます。

オフラインで何ができる？

連絡テンプレ・アイデア雛形・ToDo整理・リマインダー登録はキーなしで動作。チャット高精度・検索・画像認識はネット＋キーが必要です。失敗時は再試行ボタンが出ます。
